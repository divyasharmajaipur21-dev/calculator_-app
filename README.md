# Calculator & Personalized Greeting App

## Program Descriptions

### 1. Task 1: Basic Calculator
- Accepts two numerical inputs from the user.
- Performs addition, subtraction, multiplication, and division.
- Includes division-by-zero error handling.

### 2. Task 2: Personalized Greeting
- Accepts the user's first name and last name.
- Combines the names into a full name using f-strings.
- Displays a personalized greeting message.
